# 00.21 — просмотр изменений по файлам

Полученный от bridge patch индексируется только для отображения. Пути не открываются, команды не выполняются, кнопки Apply нет. Заголовки Git/unified diff, C-quoted octal UTF-8 пути, переименование, удаление и binary обрабатываются отдельно. Неизвестные форматы сохраняются как текст; combined diff не интерпретируется как обычная статистика.

Ограничения индекса: 256 KiB, 8192 исходных строк, 128 файлов. При ограничении/оборванном hunk показывается предупреждение; счётчики обозначают видимые добавленные/удалённые строки, не полную статистику проекта. Управляющие ASCII-байты отображаются явно. Это не patch-валидатор для применения изменений.

## Управление

Вкладка Файлы: Up/Down выбирают файл, X открывает. Внутри — прокрутка, предыдущий/следующий файл, поиск и переход к совпадению. O/Esc возвращает в список. Поиск — точное совпадение с учётом регистра по имени и полученным строкам, до 128 байт UTF-8. Не regex и не поиск на диске ПК. При смене диалога фильтр очищается. Совпадения подсвечиваются по исходным строкам, в том числе после переноса.

UI общий для Vita/SDL. Эпоха экрана не позволяет старым кнопкам работать после навигации или замены данных. Approval дополнительно привязан к ticket и полному тексту деталей; смена фокуса сбрасывает удержание. Детали всё равно подтверждаются сервером; UI не повышает разрешения.

## Проверки

`tests/diff_review_test.cpp`: парсер, лимиты, Unicode, поиск, состояния, границы элементов и отложенные кнопки; 250 детерминированных malformed samples под ASan/UBSan.

`tests/diff_git_contracts.py`: восемь отдельных сценариев с настоящим Git в НОВОЙ временной папке и C++ parser probe. Не использует пользовательскую Git-конфигурацию или файлы его проектов.

`network-tests.yml` запускает обе проверки, существующий HTTPS E2E и desktop captures. Восемь BMP включают список, выбранный diff и поиск; все подписаны TEST FIXTURE / NO CODEX / NO VITA.

Первая локальная полная HTTPS-серия остановлена timeout и не засчитывается. Изолированный ordering-тест прошёл, затем повторная полная серия прошла все 11 сценариев за 53.357s. GitHub CI отдельно подтвердил E2E, SDL-рендер и ARM-сборку; точный коммит/runs/SHA — docs/M3_DIFF_RESULTS.md. Физическая Vita, аккаунт и штатная диктовка по-прежнему не проверены.
