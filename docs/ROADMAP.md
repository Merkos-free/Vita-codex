# Дорожная карта

## M0 — GitHub и проверяемый фундамент

Исходный bridge, UI model, offline renderer, тесты, ограничения голоса, отдельная ветка и PR. Готовность исходников не равна готовности приложения. Результаты CI проверять отдельно.

## M1 — первая настоящая VPK

Воспроизводимый VitaSDK build, проверка SDK API/linker stubs, размер и заголовки пакета. На устройстве: старт/выход, русский текст, IME, кнопки/touch, микрофон 10 секунд, sleep/resume. Никакой перепрошивки/плагинов автоматически.

## M2 — настоящий Codex на Windows

Doctor установленной версии, подтверждение ChatGPT-login, разрешённый scratch directory, read-only thread. Проверить эффективные права и отказ запрещённой записи/сети; не повышать права ради демонстрации. Mock-тесты не закрывают этот этап.

## M3 — сквозной текстовый клиент

Асинхронный HTTPS, проверка сертификата, PIN, токен только в памяти/безопасном локальном хранении после отдельного решения. Реальные проекты/сессии, поток текста, stop, одноразовые approvals, читаемый diff. Проверить разрывы связи без повторного turn/start.

## M4 — встроенная диктовка

Документированный путь штатной функции Codex, доступный аккаунту без отдельного API-ключа; подтверждение условий учёта. Микрофон Vita -> штатная функция -> редактируемый текст. Отдельная отправка в thread. Если публичного пути нет — пометить блокер, не делать платную подмену.

## M5 — полировка

Крупные элементы, читаемый шрифт, управление одной рукой, пустые/ошибочные состояния, bounded history, ресурсные тесты. Релиз только с честной матрицей поддержанных версий и аппаратных проверок.
