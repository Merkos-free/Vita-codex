# Голос: без отдельной API-оплаты

Требование владельца: использовать встроенную диктовку самого Codex с его ChatGPT-login, как на компьютере. Не заменять её OpenAI Audio API, Whisper, локальной моделью, браузерным STT или другим провайдером без отдельного разрешения.

Сейчас распознавание отключено. MicrophoneProbe на Vita — только тест уровня/записи в RAM. PCM->WAV helper — проверка формата, не endpoint распознавания. Bridge не принимает аудио и не имеет операции transcribe.

Наличие audio/realtime/transcription в схеме не доказывает, что это desktop Dictate, доступно текущему плану или не имеет отдельного учёта. Doctor только сообщает символы и всегда выдаёт voiceValidated=false.

Приёмка: установить точную версию Codex, найти поддерживаемый путь этой функции, подтвердить вход через ChatGPT и условия лимитов, протестировать короткую русскую запись из Vita. Проверить отмену, приватность, потери сети, лимиты и предварительное редактирование перед отправкой задания. Не сохранять запись без разрешения.

До этой приёмки нельзя писать «голос работает» или обещать бесплатную безлимитную диктовку. Нельзя читать/переносить auth.json, cookies и refresh tokens для обращения к недокументированным внутренним сервисам. Возможный штатный audio input через виртуальный микрофон Windows — отдельный вариант исследования, пока не реализован.
