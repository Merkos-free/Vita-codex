# Windows Companion — тестовая графическая оболочка

Не стабильный релиз. Это локальное окно управления Bridge, не копия приложения Codex и не эмулятор Vita. Владелец разрешил автономную разработку: запуск на своей приставке сейчас не нужен.

## Что делает

Выбор IP, отдельного проекта, официального Codex и НОВОЙ личной папки вне проекта. «Подготовить» запускает существующий инспектор схемы и OpenSSL для сертификата. Ни модель, ни сервер в этот момент не запускаются. «Запустить» отдельно проверяет read-only/on-request, ключ/сертификат, схему и ChatGPT-login; только затем открывает выбранный локальный HTTPS-порт и показывает одноразовый PIN.

«Остановить» отзывает подключение и завершает собственный процесс app-server. Это не откат изменений и не гарантия остановки его фоновых команд. На закрытие работающей оболочки требуется подтверждение. Если идёт проверка схемы, остановка ждёт её ограниченного timeout, не запускает сервер после отмены. Повторный запуск запрещён до завершения предыдущего рабочего потока.

После остановки кнопка «Сохранить комплект для Vita» экспортирует ровно ca.pem, connection.json, CERTIFICATE_SHA256.txt. Проверяется их соответствие сертификату и адресу сервера. Существующий ZIP не перезаписывается. server-key.pem и другие личные файлы не включаются. Архив распаковывается в ux0:data/vita-codex/ позднее, когда владелец решит тестировать устройство.

## Запуск исходников

`python run_companion.py`. Нужны Python 3.11+ с Tkinter, установленный официальный Codex и OpenSSL для подготовки сертификата. Старт GUI не выполняет вход, модельные запросы, сканирование папок, изменение firewall, NAT или установку программ.

## Portable-кандидат Windows

GitHub Actions собирает Windows x64-папку PyInstaller. Распаковать ВСЮ папку CodexVitaBridge, запускать CodexVitaBridge.exe, не только отдельно скопированный EXE. Python/Tk включаются в пакет, но Codex, Node (при npm-установке) и утилита OpenSSL остаются внешними зависимостями. EXE не подписан; не отключать антивирус/SmartScreen и не запускать от администратора. Это тестовая сборка для владельца, не установщик и не автообновление.

Упаковка использует PyInstaller 6.22.3; фактически разрешённые зависимости записываются в evidence. Это не обещание побитово воспроизводимой EXE. Контрольные суммы относятся к конкретной сборке.

## Проверка без владельца

`python -m unittest discover -s tests -p test_companion.py -v` проверяет конфигурации, экспорт и остановку, в том числе настоящий локальный TLS, но с явно подставным Codex. `scripts/companion_smoke.py` открывает реально собранную EXE на Windows CI, подтверждает idle/no runtime/no voice и закрывает окно. Это не тест личного аккаунта, реального микрофона, UI на мониторе владельца или эффективности sandbox.

Никакого распознавания речи в GUI нет. Требование штатной диктовки самого Codex сохраняется; API-оплата/другой распознаватель не добавлены. Аппаратная проверка Vita, аккаунт и полный лицензионный аудит перед stable остаются открытыми.
