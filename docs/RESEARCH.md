## Проверка при импорте 2026-10-03

В справке OpenAI указано прекращение поддержки untrusted начиная с CLI 0.149.0; отдельные примеры App Server ещё показывают unlessTrusted. Поэтому документация сама по себе недостаточна: приложение проверяет конкретные поля схемы установленной версии, а несовместимость блокирует запуск. По умолчанию read-only с on-request; без автоматического повышения прав.

Схема не подтверждает фактический sandbox, доступность Dictate, лимиты тарифа или совместимость устройства. Эти проверки остаются отдельными gates.

В предыдущем исследовании рассматривались GBAtemp, Reddit, специализированные каталоги и авторские репозитории. Доступ к 4PDA был неполным; гарантированного обзора всех новых обсуждений нет. На основании этих заметок нельзя объявлять чужие порты или наш клиент аппаратно проверенными.
