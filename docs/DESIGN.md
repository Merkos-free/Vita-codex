# Реализуемый дизайн

960×544, тёмный фон, графитовые панели, голубой акцент, системный шрифт. Текущий C++ UI: Обзор, Чат, Файлы, Голос, Настройки; L/R и touch выбирают вкладку, Up/Down прокручивают текст.

Художественные изображения из обсуждения — направление оформления, не скриншоты сборки. Их мелкий трёхколоночный layout нельзя без проверки переносить на пятидюймовый экран. Для кода нужен отдельный полноэкранный режим и увеличение шрифта.

Нет выдуманных процентов, онлайн-индикаторов, моделей и результатов тестов. Пока native HTTPS не подключён, в шапке OFFLINE / UI PROTOTYPE. На экране файлов не должно быть кнопки Apply для diff уже записанных Codex изменений.

Будущий approval: проект, полная команда/изменение, последствия и отдельное подтверждение. Не обрезать смысл команды. Reject доступен сразу, Accept требует явного выбора; сбросить фокус при новой операции. Модель удержания кнопки проверяется host-тестом, но пока не подключена к сетевому UI.

Голос: индикатор записи, stop/cancel, предварительный текст и отдельная отправка. В M0 есть только локальный тест микрофона; он не отправляет аудио. При выходе/смене вкладки запись прекращается и буфер очищается.
