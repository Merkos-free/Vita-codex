## Исправления

Реальный компилятор обнаружил несовместимость `char16_t*` с `SceWChar16*`; исправлено ограниченным UTF-8 -> UTF-16 преобразованием без permissive-флагов. Добавлено редактирование текущего черновика и сохранение его при отмене IME.

Реальный линкер обнаружил зависимость libvita2d от `SceAppMgr_stub`; добавлена нужная библиотека вместо обхода ошибок.

Микрофонный индикатор не накапливает запись. Обрабатывается и очищается один блок 256 сэмплов / 512 байт. Остановка по времени, длинной паузе, ошибке, выходу/смене вкладки и системным событиям питания. Аппаратное поведение callback и sleep/resume пока не проверено.

Иконка и LiveArea генерируются оригинальным геометрическим скриптом без сторонних шрифтов или картинок. Компиляция идёт с -Wall -Wextra -Werror, в контейнере без сети и credentials, с фиксированным digest SDK.
