# Статус: подключаемый кандидат 00.20 + Windows Companion

Проект `Merkos-free/Vita-codex`, публичность не менялась. Разработка идёт автономно; аппаратная проверка отложена владельцем, не объявлена пройденной. PR #7.

## Реализовано

Общий C++ JSON/HTTPS/Session/UI на Vita и компьютере. Шесть экранов, выбор проекта/диалога, черновик, send, история user/assistant, статусы инструментов, полноэкранный diff, одноразовые approvals, CA/PIN, interrupt и восстановление потерянного ответа без автоматического повтора. Нативная сборка libcurl multi. Голос — только локальный микрофонный индикатор, не распознавание.

Bridge v2: requestId для мутаций, bounded RAM-журнал, отказ при конфликте/переполнении, status lookup без повторного действия. Interrupt не зависит от общей очереди. История ограничена 64 сообщениями/64 KiB UTF-8. Resume не сбрасывает active/unknown в idle. Старые snapshots, полученные после нового действия, теперь отклоняются по revision; регрессионный HTTPS-тест воспроизводил ошибку на предыдущем коде.

Windows Companion: настоящее графическое окно Tk, подготовка через существующие Codex/OpenSSL, отдельный запуск/остановка, локальный PIN, контроль собственного процесса и отзыв токенов, экспорт ровно трёх публичных файлов. Конструктор GUI не запускает сервер, Codex или модель. В GUI разрешён только read-only режим; CLI не повышает права автоматически. Есть настоящая Windows x64 portable EXE, не установщик; Codex/Node и OpenSSL устанавливаются отдельно. Подписи издателя нет.

## Сборка и выдача

SDK image закреплён по digest. curl 8.17.0 пересобран по SHA-256 из-за ABI-несовместимости SDK; OPENSSL_NO_UI_CONSOLE не отключает верификацию сертификата. В GitHub доступны VPK, Windows portable, source bundle, evidence и шесть BMP компьютерного рендера. Последние помечены TEST FIXTURE / NO CODEX / NO VITA; это не аппаратные скриншоты. Бинарники остаются тестовыми кандидатами, а не stable release.

## Что не подтверждено

Физическая Vita: запуск/шрифт/IME/touch, Wi-Fi/TLS, память/задержки, suspend/resume, микрофон. Аккаунт владельца, модельные задания и эффективная изоляция файлов/MCP не проверены. Встроенная диктовка не реализована, платной STT-подмены нет. IPv4:port без DNS/интернет-туннелей. Diff пока одной областью; GUI подготовки требует внешний OpenSSL. Лицензии точных статических зависимостей и лицензия оригинального кода требуют отдельной приёмки перед stable.

Следующие автономные задачи: per-file diff/поиск, UI-state тесты, читаемость, уточнение диагностики и исследование поддерживаемой штатной диктовки. Не требовать аппаратной проверки для продолжения этих задач.
