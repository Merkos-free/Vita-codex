# Статус этапа GitHub bootstrap

Дата: 2026-10-03. Цель: `Merkos-free/Vita-codex` (public, создан владельцем).

Импортируется исходный starter с обновлёнными документами и исправлениями совместимости. Добавлены безопасное разрешение Windows npm launcher без cmd.exe, проверка enum конкретных полей схемы, блокировка несовместимого запуска, read-only default и 16 новых тестов. Убраны устаревший Publish-GitHub.ps1 и первоначальный SOURCE_MANIFEST: теперь источником версий служит Git.

Проверено локально на Linux: 55 Python tests, 35 grouped C++ checks. Исходный архив отдельно воспроизводил 39 Python tests.

НЕ выполнено: настоящий Windows Codex, модельные запросы аккаунта, Vita cross-compile, запуск VPK, native HTTPS, встроенная диктовка. GitHub CI имеет отдельный статус на странице checks; этот файл не объявляет его успех до выполнения.

Следующий результат: зелёный CI исходников, затем первая подтверждённая кросс-сборка UI-прототипа. После проверки аппарата — соединение UI с bridge.
