# Статус: подключаемый кандидат 00.20 / PR #7

Проект `Merkos-free/Vita-codex`. Владелец разрешил автономную разработку без ожидания аппаратной проверки; hardware_tested остаётся false.

## Реализовано

Общий C++ JSON/HTTPS/Session/UI для Vita и компьютера. Шесть экранов, выбор проекта/диалога, черновик, send, история user/assistant, статусы инструментов, full-screen diff, одноразовые approvals, настройки CA/PIN, остановка и восстановление потерянного ответа без повторного выполнения. Нативная сборка использует libcurl multi. Голос — только локальный микрофонный индикатор, без распознавания.

Bridge v2: обязательный requestId для мутаций, bounded журнал, конфликт/переполнение закрывают операцию, status lookup не исполняет действие повторно. Interrupt не зависит от общей очереди. История ограничена 64 сообщениями/64 KiB UTF-8. Новая resume-сессия не считается idle, когда сохранён активный turn; существующее unknown не очищается.

CLI-помощник setup создаёт read-only конфигурацию, сертификат на 30 дней и отдельную PUBLIC-папку для Vita. Не запускает модель, сервер или изменение firewall. Графическая Windows-оболочка пока не написана.

## SDK-проблема устранена без ослабления TLS

В pinned SDK готовый libcurl был ABI-несовместим с OpenSSL. curl 8.17.0 пересобран по проверенному SHA-256. Для отсутствующего UI_OpenSSL использован upstream OPENSSL_NO_UI_CONSOLE: отключены ненужные консольные engine/provider hooks, не верификация сертификата. Явно подключён pthread runtime. Компиляция без сети/credentials.

## Не подтверждено

Физическая Vita: запуск/шрифт/IME/touch, реальный Wi-Fi/TLS, задержки/память, suspend/resume, микрофон. Аккаунт владельца и модельные задания не использовались. Эффективная изоляция файлов/MCP не проверена. Штатная диктовка не реализована. Поддерживается IPv4:port, без hostname/DNS/интернет-туннеля. Diff пока одной прокручиваемой областью, история ограничена. Windows GUI/EXE и финальная визуальная полировка впереди. Stable release не объявлен.
