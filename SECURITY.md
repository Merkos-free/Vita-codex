# Security / границы доверия

Это персональный экспериментальный клиент, не публичный многопользовательский сервис.

Секреты ChatGPT остаются у официального Codex на ПК. Bridge не читает auth.json/cookies и не имеет OpenAI Audio API. Дочерний процесс запускается argv без shell, API-key переменные удаляются. Локальная установка Codex, PATH, Node.js и конфигурация считаются доверенными; проверка имени npm-пакета не подтверждает издателя.

Сопряжение: шестизначный PIN, 120 секунд, максимум пять попыток, одно устройство. Случайный токен устройства действует 24 часа; в памяти сервера сохраняется хеш. Перезапуск отзывает токены. PIN и токен нельзя публиковать.

Транспорт: HTTP только loopback; LAN требует TLS 1.2+, сертификат и ключ. Проверка сертификата на будущем Vita-клиенте обязательна. Browser Origin отклоняется. Нет CORS, raw-RPC, произвольного shell endpoint, отключения TLS или публичного туннеля. Тело запроса ограничено 32 KiB, одновременные соединения ограничены.

Проекты задаются локальным allowlist. cwd возвращаемой сессии должен совпасть с проектом. Это проверка маршрутизации, НЕ доказательство файловой изоляции. Read-only и workspace-write могут иметь доступ чтения за пределами проекта; MCP/плагины официального Codex также нужно проверить отдельно.

Default: read-only + on-request; устаревшие untrusted/unlessTrusted и never отвергаются. Явный workspace-write может выполнять допустимые действия без отдельного prompt. Не обещать approve каждого изменения. Проверка схемы не доказывает фактические sandbox-ограничения: до реальных проектов обязателен scratch-test на Windows.

Подтверждения команд/файлов одноразовые и истекают; неизвестные запросы отвергаются. Timeout отправки помечает результат неизвестным, автоматический повтор запрещён. Interrupt и закрытие bridge не откатывают файлы и не гарантируют остановку всех фоновых процессов.

Известные пробелы: не выполнены native TLS, reconnect/suspend, effective-permissions smoke-test, аппаратный ввод и голос. Не использовать с чувствительными production-проектами до этих проверок. О проблеме сообщать без токенов, записей голоса и приватного исходного кода.
